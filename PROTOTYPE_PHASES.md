
# Prototype Model – phase-wise record

## Phase 1: Requirement gathering
Farmers need location-specific forecasts, crop and growth-stage inputs, understandable alerts, and local-language access.

## Phase 2: Quick design
Design the React dashboard with farm details, current weather cards, seven-day forecast, alerts, crop advice, Gemini advisory and alert history.

## Phase 3: Initial prototype
Build the React/Vite interface and Flask endpoints. Use example screenshots or mock data during early feedback if needed.

## Phase 4: User evaluation
Ask intended users, classmates or the project guide to try the application. Record actual comments about location entry, language clarity, alert usefulness and layout. Do not invent evaluation results.

## Phase 5: Prototype refinement
Improve the form, mobile layout, translations, chart readability and advisory wording based on feedback.

## Phase 6: Final product development
Integrate Open-Meteo weather data, rule-based alert detection, Gemini advisory generation through Flask, and SQLite alert history.

## Phase 7: Testing and deployment
Test valid/invalid places, weather API errors, alert thresholds, all three languages, Gemini key missing/invalid, and history persistence.
